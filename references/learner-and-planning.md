# 学习画像与课程计划

## 开课与偏好

从用户已经提供的信息确定学习目的、已知程度、题材口味和可用时间。缺少程度时先用暂定 A1–A2 方向；明确零基础时从启蒙短句开始。可在首段阅读后邀请回答两三个句子或表达小题，用户可跳过。不开长问卷，不把诊断作为开始故事的门槛。

`profile` 保存自述 / 用户选择：level、levelProvisional、目标词数、newItemsLimit（重点上限，200 词默认 6，长篇默认 10）、dailyMinutes（默认 25）、teachingBatchSize（默认 4）、quizBatchSize（默认 3）、difficultyPreference（句式难度 adaptive / fixed），以及 reviewPolicy / reviewItemsPerDay。newVocabularyPreference 默认 adaptive；用户明确固定新增重点节奏时记录 fixed，保持其要求。用户自述熟悉的词是偏好信息，不能代替测验证据。已建立课程保留其明确上限和旧复习策略。

`learner` 保存实际答题：词汇理解 vocabulary、语法 grammar、独立表达 expression 的尝试数、独立正确次数和最近 20 次证据。提示后正确与看答案后的复述均不计独立正确。随堂练习可用于了解弱项，但不解锁课程或推动复习日期。旧版证据保留，不凭旧版单一目标反推三个新维度已掌握。

## 确定本次难度

`status.learningPlan` 是统一计算结果。至少通过两个不同学习片段、三个能力各至少 5 次回答才给调整建议；同片段补测不算新片段，最近表现按不同片段取最后一次结业结果。阈值是本技能的教学配置，不是已验证的能力诊断标准。

- 样本不足：保持暂定程度，根据具体问题补讲。
- 有维度近期独立正确率低于 60%：建议 simplify。减少新项数量、缩短句子或降低一个结构的复杂度，完整讲解与过关门槛保留。
- 三个能力近期独立正确率均至少 90%，且最近两次结业测验均独立满分：建议 challenge。只增加一种难度，例如多一个时间从句；不同时增加词量、篇幅和语法。
- 其他情况：maintain，根据错误类别补讲。
- 用户设置 fixed：不自动提高或降低其指定难度，可报告观察到的弱项。

将结果用于下一片段的教案选择，不宣称机器确定 CEFR 等级。时间预算用于分配阅读、讲解和复习量，不虚构用户的学习耗时。按 reviewPlan 分批处理积压；超出 balanced 日计划的旧项仍保留真实到期，不伪称已复习。明确暂缓才 waive，本段考核门槛保留。

## 内容与词汇计划

设定中保存主线目标、人物成长、已发生事件和未解决伏笔。学习片段按 serial 标注 arcId / chapterId / sceneId；场景可以跨多个片段，用户读完一段获得行动或情绪进展，不必每 200 词遇见新怪兽或出现大反转。

每片段选少量新的必学知识；`learningGoals` 为语法 / 理解 / 表达目标标 ID。旧词复现遵从 `recyclePlan`：错题和未稳固维度优先、再到期项、再语境单一或曝光较少项。自然融入 2–5 项即可；语言和情节不适合时可以少用或暂不使用，记录实际发生的复现。

续写前同时看 status.vocabularyPlan。newItemsLimit 是重点总上限，不是每段必须新增的数量；可选已经学过的词作为本段 focus，在新动作、关系或生活语境中再次解释和独立应用。recommendedNewFocusCount 为 0 且 preferExistingFocus 为 true 时，故事继续推进，主要练旧词迁移与适合程度的语法，不另塞一批新词。所有本段必学目标仍照常考核，用户明确指定的不熟词照常记录，不因预算忽略。

负担模拟比较不新增、每段用满上限和较少新增的六十天队列。假设每天完成一个片段、所有到期回忆独立正确、每天按固定词条预算复习；扣除今天已完成预算，不写未来成绩、不改变真实日程。这是排课近似，不预测遗忘率或耗时，也不保证长期无积压。一个片段实际需要多天时，建议偏保守，按真实节奏与回答调整；不能为了模型而强迫每天学完整段。候选新增为 0–5 项，第一课没有旧词且低预算时仍可从一个新重点开始。

newVocabularyPreference 为 fixed 时，保留用户指定节奏，adaptiveSuggestion 仅供其选择；简短说明预计负担后按要求授课，不默默降低其目标。减少新增不等于减少故事词数、句子讲解或情节发展；熟悉词照样可以写出新的行动与悬念。

`reuseContexts` 使用本片段的真实句子和语境标签，例如 rescue-radio、quiet-corridor、daily-conversation。新情境须有表达或搭配变化，仅换人名不当成有效迁移。exposure 的次数和日期只是接触记录；学习后的阅读复现与实际答题证据分别保存。

开课、改主线和用户改口味时更新明确偏好；人物事实、能力代价和已解决伏笔不能在续写中默默消失。数组事实按追加 / 稳定 ID 更新，重大修订明确记为修订或支线。
