# 教学与考核

词义、用法和表达的已知错误分别修复。词义题答对不能清除尚未答对的表达错误；复习须针对仍未达标的维度换题，直到它得到独立正确证据。

## 读故事与逐句讲通

先展示标题、目标难度、实际英文词数与完整原文。正文不夹杂中文释义。然后按 S01、S02…讲解；一句里的对白和叙述可以同属一个单元，保证所有英文顺序不变、没有遗漏。

### 极速理解优先 · 八阶标准化立体精讲流水线

单句精讲严禁简单罗列单词中文和空洞的“主谓宾”标签，每次推送 2–3 句，每句严格按以下八阶结构展开：

1. **阶段一：三步极速拆读法 (Fast Comprehension 3-Step)**
   * **第一眼·3秒抽主干**：剥除所有修饰语，提取最极简的核心裸句（谁 + 做了什么 / 处于什么状态），瞬间在大脑中建立锚定画面。
   * **第二眼·意群顺读还原**：按英语原生思维从左到右分意群顺读，像电影推轨镜头一样建构画面，坚决摒弃“看完整句再倒着拼中文”的思维死穴。
   * **第三眼·顺藤摸瓜回填修饰**：剖析定语、状语、介词短语如何精确补充环境、程度、触感与空间细节。
2. **阶段二：语法结构全景拆解 (Grammar Architecture)**
   * 提供清晰的句式结构公式（如 `Compound Sentence = Clause 1 + and + Clause 2`）；
   * 深度解剖主谓宾/系表/复合句/从句/非谓语动词结构，剖析时态语态的选择动机；
   * 指出该语法结构的核心考点与规则避坑（如半否定副词位置、就近一致原则、反身代词用法等）。
3. **阶段三：固定搭配与短语宝典 (Fixed Phrases & Collocations)**
   * 独立归纳句中出现的高价值固定短语与动词搭配；
   * 给出搭配公式、同类词族对比（如 `blink at` vs `blink in`、`hardly stand` vs `barely stand`）；
   * 提供生活与小说实战迁移例句。
4. **阶段四：核心词汇网络与深研 (Lexical Network)**
   * 词根词缀构词法透视、近义词色调梯队辨析（如 *strange* vs *unfamiliar* vs *alien*）、熟词生义与隐喻。
5. **阶段五：中英思维转换与避坑指南 (Cognitive Shift & Pitfalls)**
   * 对比英汉思维差异（如客体具象化主语 vs 动词驱动、身体部位所有格归属等）；
   * 指出中国学习者常见的中式英语（Chinglish）误区并给出地道修正方案。
6. **阶段六：文学修辞与镜头美学 (Literary Insight)**
   * 分析选词在小说叙事中的微观镜头景别调度（特写、全景、POV视角）、戏剧张力与氛围营造。
7. **阶段七：纯英文脱拐回读 · 自主理解测试 (Independent Comprehension Check)**
   * 关键教学闭环：在进入发音之前，单独再次输出该句**纯英文原句（不带任何中文翻译与解释）**，引导学习者遮住解析直接顺读，检验大脑是否已完成脱拐画面建构。
8. **阶段八：发音语流与听读技巧 (Phonics & Connected Speech - Closing Reference)**
   * 置于最后收尾，作为朗读与听力参考；标注意群停顿线、连读（Liaison）、不完全爆破（Unexploded Stop）、功能词弱读（Weak Form）等技巧。

每个教学单元在权威档案中保存以下字段：

| 字段 | 内容 |
| --- | --- |
| `english` | 原句，保持原有拼写和标点 |
| `meaning` | 中文自然释义；需要时补一句说明英语与中文的表达差异 |
| `chunks` | 按意群拆分，标注各部分在句中的作用 |
| `grammar` | 初学者先说“谁 / 什么、做什么或处于什么状态”，再按需标示主语、动作词、状态连接和修饰；时态、从句、省略或标点用当前句解释，术语后置 |
| `words` | 语境词义、短语整体含义、功能词作用和必要的辨析；已讲基础词可明确引用之前的单元 |

不把“结构：主谓宾”当作完整解释。比如 *The door slid open before I could reach it.*，应说明 *slid open* 是动作加结果状态；*before I could…* 表示还没来得及做到，而不是只列词义和“过去时”。这是教学示例，不替任何课程创建学习记录。

对每个重点项，记录：

- `term`、`kind`（word / phrase / pattern）、稳定语义标识 `sense` 和 `meaning`。
- `pronunciation`：英 / 美选择、可靠的 IPA 或发音分解、重音；多词短语可讲连读而不编造统一词典音标。
- `usage`：词性、可数性 / 动词形式、常用搭配、故事里的实际含义及必要辨析。
- `memory`：真实构词可用词根词缀；否则用画面、动作、角色与声音作记忆钩子。联想和词源明确区分，拼写相似不代表同源。
- `example`：正文例句及一个新语境的实用例句；新语境使用户学会脱离故事使用。

基础词也应讲清，但只将当集重点、答错项和用户指定的不熟项加入复习库。句型与短语可一起复习。用户说某词已熟悉时记录其偏好；出现实际错误时再提议纳入重点。

## 真实答题与补测

先核对脚本返回的 `requiredTargets`。新课程重点项各有 `item:<词条 ID>:meaning`、`:usage`、`:production` 三个维度；`learningGoals` 指定的语法点以 `goal:grammar:<ID>` 分别验收，理解与表达目标亦可逐项指定。未指定细项时保留 comprehension / structure / transfer 通用目标。旧版未完成测验沿用已保存的目标，不能在迁移时替换题目。

词义题验证语境含义，用法题验证搭配 / 词形 / 结构，表达题验证在新语境中的实际使用。生产型回答可同时证明用法和词义，但须在 criteria 中给出每个维度的明确依据；只选中正确词义不能标成能表达。可用四类题：

1. 情节理解：用自己的话解释行动、动机或因果，而不是机械复述原文。
2. 词与搭配：在新句中填空、解释语境义、辨别搭配或将中文意图表达成英语。多选题可辅助，但不能全部只靠识别。
3. 句子结构：找主干、解释从句关系、改写时态、修正一个真实易错点。
4. 迁移表达：用目标词或句型写一两句新场景内容，并说明或从句子中证明用法正确。

一个题组可以含多个单独编号的小题。保存完整试卷，每次用 next-questions 给约三道未答题；用户分批作答即保存，不重新换卷。题目 expected 给参考答案与可接受变体，criteria 给得分条件；targets 只能对应本段目标或复习词条。综合题可用 targetMarks 分开保存每个目标的 score / assistance / feedback，整体 score 取原始分最低值。评分不能让一个总分抹掉独立正确的维度。

发布问题后等待用户回答。回答模糊或缺失时追问该小题，不代用户填答案。评判语义与用法；允许合理变体。批改展示“你的答案 → 得分与原因 → 修正 / 更自然表达”。文本题只能证明文本能力，不能据此声称发音已过关。

得分与提示记录：

| `score` | 解释 | 解锁贡献 |
| --- | --- | --- |
| 0 | 错误或无法作答 | 未掌握，补讲与次日复习 |
| 1 | 部分正确 | 尚需补测 |
| 2，`assistance: none` | 独立正确，允许同义变体 | 目标通过 |
| 2，`assistance: hint` | 得到提示后正确 | 尚需换题独立验证 |
| `assistance: answer_seen` | 看过完整答案后的回答 | 当作练习；不证明掌握 |

错误后先定位：忘了词义、搭配不熟、结构不明、情节误解或迁移困难。给一个针对性的解释与练习，再换语境补测。`reteachNotes` 保存补讲内容。可只补未通过目标；先前已通过的目标保留，但若同一次测验又错则撤销对应证据。

默认要求所有必学目标通过。档案中的 `passed` 是当集过关证据，不是长期熟练程度保证。用户要求跳过时使用 `waive`，单独记为 `waived`。

## 随堂小练习

先展示全文与知识地图，再按 profile.teachingBatchSize 分组。句组后可提出 1–2 个短问题，使用 quiz scope: practice 保存真实回答；用户只想连续听讲时可以省略。已保存的可选练习要先不做时，以 dismiss 保留原请求和已答部分；当前仍为 teaching，不跳过正式结业。答错补讲、答对记录反馈，均不推动词条掌握或复习间隔。

## 复习轮

status 返回到期项和 reviewPlan，本日错题优先修复，再处理选定的旧项。新课 balanced 默认每天 5 个，短时间新课 3 个；完成日计划后可接故事，剩余积压保持真实到期，不能全标完成。strict 课程仍全部完成才续写。通过 quiz scope: review 保存题目、answer 更新日期，用户主动要求可多复习。

复习采用主动回忆：给中文意图、句子空缺、情境任务或结构改写，允许用户先说“不会”。错题先反馈再补测；提示后正确还不能解除错题门槛。原文再读、教师举例和用户自称已熟只记录曝光或偏好，不作为独立回忆结果。

长期复习轮换词义、用法和独立表达，优先弱维度；可对已有项采用 `item:ID:<维度>`。兼容旧题的 `item:ID` 只记录回忆表现，不据此补填三个维度全部正确。

日期由脚本统一计算。一个词对应的所有题目批改齐全时，按实际回答日期记录回忆，不等待无关题目；整套答完才判定结业和画像。跨日续答不推迟已完成词条的复习，单日重复或提前答对不延长间隔。长停学先给短剧情回顾，再按日计划恢复；没有复习的旧项仍待复习，不因日计划结束而改日期或标掌握。
